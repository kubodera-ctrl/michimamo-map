# まちイベ 全国「場所タイプ」・モール収集仕様

更新: 2026-09-22

## 目的

全国のイベントを、内容だけでなく「どこで開催されるか」から探せるようにする。

特にモール・商業施設は、キャラクター、ヒーロー、インフルエンサー、ライブ、ワークショップ、親子向け体験が多いため、全国収集の重点ソースとする。

## 場所タイプ

イベントは1つ以上の `venue_type_keys` を持つ。複数可。

- `park_plaza` — 公園・広場
- `mall` — モール・商業施設・大型店
- `event_venue_indoor` — イベント会場（屋内）
- `event_venue_outdoor` — イベント会場（屋外）
- `hotel` — ホテル・宿泊施設
- `amusement` — レジャー・アミューズメント
- `culture_public` — 博物館・美術館・科学館・公共文化施設
- `other` — その他

例:
- モール内ホール → `mall + event_venue_indoor`
- テーマパーク屋外ステージ → `amusement + event_venue_outdoor`
- 公園内特設会場 → `park_plaza + event_venue_outdoor`

## 検索UI

場所タイプは**チェック式の複数選択**。

- 初期状態: 全タイプ選択 = すべて表示
- チェックを外したタイプ: 検索結果から除外
- 複数タイプ: OR検索
- 全解除: 0件になることを明示
- 「すべて」「全解除」ボタンを用意
- ページ送り・保存検索でも選択状態を維持

ユーザーが「モールだけ」にすれば `mall` を持つイベントだけ表示される。

## モール収集

### 優先して拾う

- キャラクターショー
- プリキュア等のヒーロー・アニメイベント
- インフルエンサー出演
- ライブ / ミニライブ
- ワークショップ
- 体験イベント
- 親子イベント
- 展示・謎解き
- 季節イベント
- 地域連携イベント

### 原則イベント検索から除外

- ポイント倍増だけのキャンペーン
- クレジットカード入会施策
- 通常セール
- 営業時間変更
- 新店/閉店のお知らせ
- 商品販売だけのPOPUP
- 常設店舗ニュース

ただし「POPUP + キャラクター展示」「購入に加えて体験・撮影・ステージがある」等、来場目的になるイベント性がある場合は候補化可能。

## 全国収集フロー

1. モール運営会社・施設公式のイベント一覧URLを情報源台帳へ登録
2. 規約確認前は `automated_fetch_allowed=false`
3. 新規候補を発見
4. 販促キャンペーンとイベントを分離
5. 個別公式詳細で日付・会場・料金・対象・予約等を確認
6. `venue_type_keys` を確認して付与
7. キャラクター/作品/インフルエンサーは fandom link を確認
8. 体験は experience taxonomy を確認
9. verified + publish gate を通して公開
10. 更新差分で中止・延期・終了を追跡

## 全国モールで重要なこと

同じ全国企画でも施設ごとに開催日・内容・整理券条件が違う場合がある。

そのため「全国キャンペーン1件」として雑にまとめず、検索では**実際の開催施設・開催日単位**を優先して正規化する。

例:
全国企画 → 東京会場 / 大阪会場 / 福岡会場を別occurrenceまたは別eventとして扱う。

## 自動分類

施設名や情報源から `mall` の候補を自動付与してよいが、公開確定前に確認する。

「○○モール」「ららぽーと」等の名称一致だけで、屋内/屋外までは推測しない。
屋内外は実際の開催場所（館内、屋外広場等）を公式詳細で確認する。

### 具体的な分類例

- 独立した野外ステージ → `event_venue_outdoor`
- 公園内の野外ステージ → `park_plaza + event_venue_outdoor`
- 商業施設の屋外ステージ → `mall + event_venue_outdoor`
- イトーヨーカドー等の大型店店内イベント → `mall + event_venue_indoor`
- イトーヨーカドー等の店頭広場イベント → `mall + event_venue_outdoor`
- テーマパーク内の野外ステージ → `amusement + event_venue_outdoor`
- 文化センター・市民会館・公民館・自治体ホール → `culture_public`
- 文化センター等のホール開催 → `culture_public + event_venue_indoor`

`other` は、寺社・駅構内・学校・企業敷地など、既存分類のいずれにも自然に当てはまらない会場に限定して使う。
