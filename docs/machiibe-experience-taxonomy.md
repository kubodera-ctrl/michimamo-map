# まちイベ「体験」分類

更新: 2026-09-22

## 目的

「体験」を単なるキーワードではなく、全国検索で使える独立した検索軸として扱う。

イベントに体験要素がある場合は、原則として `category_keys` に以下を付ける。

- 全体タグ: `experience`
- 詳細タグ: 該当する `experience_*` を1つ以上

詳細タグだけを付けず、原則として `experience` も併記する。

## 詳細タグ

| key | 表示 | 例 |
| --- | --- | --- |
| experience_gem | 宝石・鉱物・化石探し | 宝石探し、鉱物採集、化石発掘 |
| experience_fishing | 釣り・魚つかみ | 海釣り、釣り堀、ニジマスつかみ |
| experience_glass | ガラス細工 | 吹きガラス、とんぼ玉、サンドブラスト |
| experience_ring | 指輪・アクセサリー作り | リング、シルバー、天然石アクセサリー |
| experience_pottery | 陶芸・焼き物 | ろくろ、手びねり、絵付け |
| experience_craft | 工作・クラフト | キャンドル、レジン、革小物、石けん |
| experience_woodwork | 木工・DIY | 木工、家具、小物DIY |
| experience_food | 料理・お菓子・食品づくり | パン、ピザ、和菓子、食品工場体験 |
| experience_farm | 農業・収穫 | いちご狩り、芋掘り、田植え |
| experience_animal | 動物ふれあい・飼育 | 乗馬、乳しぼり、飼育体験 |
| experience_science | 科学・実験 | 実験教室、プログラミング、科学工作 |

| experience_other | その他の体験 | 上記に当てはまらない参加型体験 |

## 判定ルール

- **見るだけの展示・ショーは体験にしない。**
- 来場者が「作る・触る・釣る・採る・乗る・試す・参加する」ことが中心なら体験候補。
- ワークショップは原則体験候補。ただし説明会・講演のみは除外。
- 「科学館だから科学体験」とは決めず、実際のイベント内容を確認する。
- 有料/無料、屋内/屋外、対象年齢は体験タグとは別に管理する。
- 複数に該当する場合は複数タグ可。例: 天然石リング作り → experience + experience_gem + experience_ring。
- AI/自動分類は候補生成まで。公式情報で内容を確認できない詳細タグは確定しない。
