# まちイベ SNS Production Master v1

更新: 2026-09-22
対象: X / TikTok
位置づけ: 正式マスターテンプレート。SNS素材生成はこの仕様を基準にする。

## 0. 基本思想

まちまも速報のProduction Masterと同じ思想を使う。

- AIは文章整理・候補生成のみ
- ロゴ、ブランド色、余白、文字領域、フレーム構成、CTA位置はコード固定
- イベントごとにデザインが別物にならない
- 事実は確認済みデータだけ。不明は不明のまま
- 自動取得と自動公開を分離
- SNSは自動投稿しない。素材生成・投稿画面生成まで
- 主導線はまちイベ、第2導線はまちまも

# 1. TikTok 正式マスター

共通仕様:
- 9:16 / 1080×1920 / 動画化時30fps
- 正式まちイベロゴ必須
- 1イベント=固定5Frame
- Frame1〜4は情報を積み上げ、Frame5は完全別エンドカード
- 5枚PNGを基本成果物とし、同じマスターからMP4も生成
- 写真なしでも成立
- 利用条件未確認の画像・動画は使用しない

## Frame 1 — HOOK

目的: 一瞬で「行きたいかも」と思わせる。

固定:
- まちイベロゴ
- 地域
- フック
- イベント名

フック例:
- 今週末、ここ行きたい
- 雨の日でも遊べる
- 子どもが主役の体験
- 宝石探し、やってみる？
- 入場無料で楽しめる
- ○○好きならチェック

禁止:
- 根拠のない「絶対」「日本一」「大人気」
- 混雑・人気・満足度の推測
- 実際にない体験内容

## Frame 2 — VISUAL + WHAT

素材優先:
1. 利用許諾・ライセンス確認済み公式動画
2. 利用許諾・ライセンス確認済み公式画像
3. 運営者提供の利用可能素材
4. まちイベ固定カテゴリービジュアル

公式ページに画像があるだけでは利用可と判断しない。

表示:
- イベント名
- 開催日
- 地域
- 公式情報から要約した1〜3ポイント

## Frame 3 — FACTS

固定レイアウトで最大6項目:
- 開催日
- 時間
- 会場
- 料金
- 対象
- 予約

必要に応じて屋内、雨の日、未就学児、ファミリー、配慮情報を補助表示。
未確認は「不明」「公式情報を確認」。

## Frame 4 — WHY GO

まちまも速報Frame3の「内容に合わせて自動切替」をイベント用に転用。
デザイン固定、内容だけイベントに合わせる。最大3ポイント。

優先:
1. 体験 — 「こんな体験ができる」
2. 推し活 — 「○○好きならチェック」
3. 子ども主役/ファミリー — 「親子でチェック」
4. 雨の日/屋内 — 「雨の日候補に」
5. 無料 — 「無料で楽しめる」
6. 通常 — 「ここをチェック」

宝石、釣り、ガラス、指輪、陶芸、工作、料理、収穫、動物、科学、伝統工芸、工場/職業、アウトドア等は確認済みexperienceタグを使う。

## Frame 5 — END CARD

完全別画面。

- 詳細・条件検索は「まちイベ」
- 保存して、一緒に行く人へ共有
- 行く前・当日の周辺確認は「まちまも」
- 暑さ指数 / AED / 交番・警察署 / 周辺MAP
- リンクはプロフィールから

狙う流れ:
TikTok → まちイベ → イベント詳細 → まちまも

# 2. TikTok動画尺

SHORT:
- 20〜40秒
- 拡散・保存・共有向け
- 5Frameをテンポよく表示

LONG:
- 60〜90秒
- 十分な公式情報があるイベントだけ
- 収益化目的で内容を水増ししない
- 追加できるのは確認済みの体験内容、予約、対象、料金、会場、公式アクセス情報、まちイベ独自検索説明、まちまも導線
- 情報量不足ならSHORTのみ

# 3. X 正式マスター

目的: 速報性・検索流入・リンククリック。

固定順:
1. フック
2. 都道府県/市区町村
3. イベント名
4. 日付/時間
5. 会場
6. 確認済み特徴 最大3点
7. まちイベ導線
8. 必要に応じてまちまも導線
9. ハッシュタグ 最大3個

基本形:

【今週末のおでかけ / 新着 / 体験 等】
📍東京都 江東区
「イベント名」

📅 9/26〜9/27
🕐 10:00〜17:00
🏢 会場名

✓ 子どもが主役
✓ 屋内
✓ 参加無料

詳細・条件検索は「まちイベ」
行く前の周辺確認は「まちまも」

[まちイベURL]
#まちイベ #東京イベント #親子イベント

ルール:
- X API自動投稿はしない
- Web Intent/投稿作成画面まで
- URLはイベント詳細
- 中止・延期・完売・受付終了は通常新着投稿を停止
- ハッシュタグ最大3
- 同一イベント再投稿は日程接近・内容更新など理由を持たせる

# 4. 自動選択ロジック

投稿タイプ優先:
1. 体験
2. 推し活
3. 子どもが主役
4. 雨の日/屋内
5. 無料
6. 季節・大型
7. 通常

複数該当時は具体的価値を優先。
例: 「ファミリー向け」より「宝石探し」、「屋内」より「ガラス細工」。

フック根拠として使えるもの:
- verified event fields
- verified category/experience tags
- verified fandom relation
- verified price
- verified audience
- verified indoor
- verified accessibility
- 公式ページで確認した要約

AIはこの範囲を短く言い換えるだけ。

# 5. SNS公開ゲート

生成可能:
- publication_status=published
- verification_status=verified
- source active
- sourceが公開条件を満たす
- event_statusが通常投稿可能

通常告知を停止:
- cancelled
- postponed
- sold_out
- registration_closed

画像/動画使用時:
- 利用許諾状態を追加確認
- 不明ならブランドビジュアルへフォールバック

# 6. 管理画面

新着イベントから:
- X投稿
- TikTok素材
- SNSマスター確認

TikTok:
- Frame1〜5プレビュー
- 各Frame PNG
- 5枚一括
- SHORT MP4
- LONG MP4（条件を満たす場合のみ）
- キャプション
- コピーボタン
- 投稿前チェック

X:
- 投稿文プレビュー
- 文字数
- URL
- ハッシュタグ
- X投稿画面を開く

自動投稿はしない。

# 7. Visual Regression

Production Master化後は以下をGolden Snapshot化:
- Frame1〜5
- 長タイトル
- 長会場名
- 画像なし
- 料金不明
- 時間未定
- 推し活
- 体験
- 雨の日
- ファミリー
- 日本語/英数字混在

レイアウト差分が閾値を超えたらCI失敗。

# 8. まちまも34から引き継ぐ絶対ルール

- 固定5Frame
- AIは文章整理のみ
- UI/ロゴ/色/レイアウトはコード固定
- 内容に応じてFrame4文言だけ自動切替
- 許諾済み公式動画 → 許諾済み公式画像 → ブランド代替素材
- 事実を盛らない
- 5枚PNG + MP4を同じマスターから生成
- Frame5は完全別エンドカード
- 保存・共有・プロフィール導線
- まちまもMAP導線
- Golden Snapshot / Visual Regression

まちイベでは、まちまも速報の「注意喚起」を「イベントの魅力・適合ポイント」に置き換える。
