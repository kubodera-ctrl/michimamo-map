# 開発23→24：無料カメラ実装引き継ぎ

## 決定済み仕様
- `ROADMAP.md` の「散歩／車載モードと無料／有料の統合仕様」および危険駐停車の「0. 無料／有料の機能区分」が最新。
- 無料：散歩・車載の両モード、手動／自動撮影、連写・重複抑制、端末内の基本モザイク、確認・手動追加。
- 散歩（旧称徒歩）：固定に近い視点で同一車両を追跡。3分停止、5・10・20分で記録。遮蔽・追跡低下・カメラ移動・バックグラウンドは連続観測を切る。未観測時間は足さない。
- 車載：通過時の横断歩道・交差点・自転車通行空間などの危険候補。停車後に確認して投稿。単なる車両検知を危険状態検知と偽らない。
- 有料：月150円。追加AIによる詳しい確認・説明を利用枠内で提供。未実装につき未課金。無料機能の取り上げはしない。
- 広告特典：特典付与許可を確認した原則報酬5,000円以上の案件、成果承認・入金・予算確保後2か月解放。実案件未取得、付与機構未実装。普通の提携リンクやセルフバックを無断流用しない。
- AEDの有料画像チェックは `PAID_IMAGE_AI_PAUSED` でサーバー・UIとも保留。再開しない。

## 今回実装した動作
1. カメラ映像が再生できた後に「撮影して加工する」を有効化。
2. 1枚を端末内メモリに撮影し、長辺最大1600pxに縮小。録音なし・GPS取得追加なし。
3. 初期表示は全体モザイク。自動の顔・ナンバー検出ではない。
4. 「範囲を選び直す」で元画像を端末内で表示。指のドラッグでモザイク／黒塗り、1つ戻す、全体モザイクが可能。
5. 確認チェック後、加工済みCanvasだけをJPEGとして端末へダウンロード。元画像のダウンロード操作なし。新規Canvasのため、元写真のEXIFを持ち込む経路なし。
6. 編集が変われば確認解除。編集中／終了後の古い非同期エクスポートを破棄。描画失敗では保存を止める。
7. 終了・画面移動・バックグラウンドでカメラ停止と編集用Canvasの破棄。再読み込みでも失われる。IndexedDBやlocalStorageへ写真を保存しない。
8. エディターはQ&A修正と同様に、visualViewportとCSS zoomを考慮。ヘッダー・保存ボタンを本文スクロールから分離。

## 実装箇所
- `camera-capture.js`：撮影、範囲選択、モザイク／黒塗り、確認、JPEG出力、画像解放。
- `camera-capture.css`：撮影ボタン、加工ダイアログ。映像はcontainで表示し、プレビュー外の隠れた端を撮影する見た目の差を避ける。
- `index.html`：getUserMedia/play成功後setReady(true)、終了時reset()。既存の許可応答レースとカメラ停止処理を維持。
- `camera-guide.js`：現在使える手動機能と将来の自動機能を区別。Q&Aの×／▲とスクロール修正を保持。
- `tests/camera_capture.test.cjs`：DOM・Canvas代替を使ったロジック検証。

## 次に進める内容

5. サーバーへ候補を収集する前に、非公開・本人／管理者権限・10日削除・30日延長＋7日猶予削除を完成させる。現在の端末保存を「写真投稿完了」と扱わない。
