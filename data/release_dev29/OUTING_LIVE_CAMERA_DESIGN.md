# まちイベ × まちまも「今日のお出かけ」・周辺LIVEカメラ接続設計

更新日：2026-09-19  
状態：設計確保のみ。未実装・未収集・未公開。

## 1. 目的と役割

- まちイベ：イベントや行き先を検索し、行く場所を決める。
- まちまも：行く前・当日に、会場と周辺の現在情報を確認する。
- カメラ情報はまちイベへ重複保存せず、まちまもの共通地域情報から提供する。
- 危険情報だけの画面にせず、外出判断に必要な実用情報を一画面へまとめる。

## 2. 予定する利用者導線

1. まちイベのイベント詳細で「会場周辺の今を見る」を押す。
2. まちまもがイベントID、会場座標、イベント名、開催日を受け取る。
3. 会場座標を中心に地図を開く。
4. 「今日のお出かけ」パネルを表示する。
5. 次の順で確認できるようにする。
   - 周辺LIVEカメラ
   - 本日のWBGT
   - 近くのAED
   - 近くの交番／警察署
   - 周辺道路の安全情報
6. 地図上では公開ライブカメラレイヤーを個別にON/OFFできる。

イベントIDが共通イベントDBに存在する場合はDB上の会場座標・名称を正とする。URLで渡された名称と座標は初期表示の補助であり、HTMLとして解釈しない。座標範囲、文字数、開催日、遷移元を検証する。

## 3. 接続契約案

初期URL案：

`/?mode=outing&event_id={id}&lat={lat}&lng={lng}&event_name={encoded}&event_date={YYYY-MM-DD}&source=machievent`

必須：
- mode=outing
- lat / lng（共通イベントDB照合前の初期中央位置）

推奨：
- event_id
- event_name
- event_date
- source=machievent

制約：
- 緯度は -90〜90、経度は -180〜180。
- イベント名は表示用プレーンテキスト、最大100文字。
- 不正値や範囲外座標は無視し、通常の地図起動へ戻す。
- URLだけで公開状態・公式性・開催事実を確定しない。
- 将来は署名付き短期トークンまたはイベントID参照へ移行できる構造にする。

## 4. 周辺LIVEカメラの対象

優先対象：
- 自治体公式YouTube LIVE
- 自治体・公共機関の公式ライブカメラ
- 公式観光協会・観光施設
- 港湾・海岸・河川
- 道路会社
- 国土交通省その他の公共機関
- 利用条件と提供主体を確認できた民間カメラ

対象外：
- 非公開カメラ
- 街頭防犯カメラの無断収集・再配信
- 出所不明の転載映像
- 人物監視、個人追跡、顔認識を目的とする情報
- 規約でリンク、表示、埋込等が禁止されている情報

## 5. 共通データ構造案

将来のテーブル候補：`public_live_cameras`

| 項目 | 型の候補 | 用途 |
|---|---|---|
| id | uuid | 内部ID |
| name | text | 表示名称 |
| latitude / longitude | numeric | カメラ地点 |
| category | text | 道路・河川・港湾・海岸・観光・その他 |
| provider_name | text | 提供元 |
| provider_type | text | 公共機関・自治体・公式観光団体・確認済み民間等 |
| official_url | text | 必ず利用者が確認できる公式ページ |
| stream_url | text nullable | 埋込・画像表示用URL。許可確認済みの場合のみ |
| stream_type | text | official_video_live / frequent_still / infrequent_still / external_page |
| embed_permission | text | allowed / denied / unknown |
| terms_url | text nullable | 利用条件の確認先 |
| quality | text | 4k / 1080p / 720p / unknown |
| update_interval_seconds | integer nullable | 静止画更新間隔等 |
| operational_status | text | live / offline / maintenance / unknown |
| last_status_checked_at | timestamptz | 稼働確認日時 |
| terms_checked_at | timestamptz nullable | 利用条件確認日時 |
| verified_official | boolean | 公式性の確認結果 |
| is_active | boolean | 公開候補の有効状態 |
| created_at / updated_at | timestamptz | 監査用時刻 |

必要に応じて、地域コード、表示範囲、タイムゾーン、サムネイル利用可否、確認メモ、取得方法、停止理由を別項目または管理者限定メタデータへ追加する。

## 6. 優先順位

第1条件：
- 公開中または直近確認で稼働
- 利用条件と提供元を確認済み
- 会場／現在地からの距離

同程度の距離では次を加味する。

1. 配信方式
   - 公式動画LIVE
   - 高頻度更新静止画
   - 低頻度静止画
   - 公式ページのみ
2. 画質
   - 4K / 1080p
   - 720p
   - 不明
3. 公式性
   - 自治体・公共機関・公式観光団体
   - 公式観光施設・道路会社等
   - 確認済み民間
4. 現在性
   - 最終確認日時が新しい
   - 更新間隔が短い
   - 停止・不明状態でない

距離を無視して遠方の高画質カメラを上位にしない。最初に近傍候補を抽出し、その候補内で品質・稼働・公式性を並べ替える。将来は「会場から○km」「現在地から○km」を利用者が選べる構造とする。

## 7. 表示ルール

地図ポップアップ候補：
- カメラ名称
- 提供元
- 会場または現在地からの距離
- LIVE / HD / 公式
- 道路 / 河川 / 港湾 / 海岸 / 観光
- 稼働状態
- 最終確認日時
- 「公式ライブカメラを見る」

ラベル条件：
- LIVE：配信方式と稼働を確認できた場合のみ。
- HD：720p以上を確認できた場合のみ。推測表示しない。
- 公式：提供元・公式URLを確認済みの場合のみ。

埋込条件：
- 規約または公式の埋込機能で許可を確認できた場合だけ直接表示。
- denied / unknown は公式ページへの外部遷移。
- 自動再生、音声自動再生、過剰な同時接続は行わない。
- 埋込が停止した場合も公式URLを残す。

## 8. 権限・安全・運用

- 一般利用者は公開済みレコードの読取だけ。
- 作成・更新・停止・規約確認は管理者またはサーバー処理だけ。
- 公開前に提供元、公式URL、規約、埋込可否、最終確認日時を必須確認する。
- 稼働監視は提供元規約と負荷を守り、短時間の過剰アクセスをしない。
- 停止、URL変更、規約変更、長期未確認を検知したら埋込を止める。
- 映像や画像を無断で保存・再配布しない。
- 映像から人物・顔・車両番号等を抽出、識別、追跡しない。
- 公開カメラの存在を、防犯・安全の保証として表示しない。

## 9. 段階実装

### L0 設計確保

- 本資料、データ項目、接続契約、安全境界を確定。
- 実テーブル、収集、埋込、公開は行わない。

### L1 限定地域の台帳試験

- 公式カメラを少数地域で手動登録。
- URL、稼働、規約、座標、画質、表示ラベルを確認。
- 国交省だけへ偏らず、高画質の自治体・観光・港湾等も比較。

### L2 まちまも地図レイヤー

- 公開ライブカメラのON/OFF。
- 距離と品質を考慮した一覧。
- 原則は公式ページへの遷移から開始。

### L3 今日のお出かけ

- 会場座標を中心にパネルを表示。
- LIVEカメラ、WBGT、AED、交番、道路安全情報を統合。
- 位置拒否時も会場座標を基準に利用可能。

### L4 まちイベ接続

- まちイベ詳細の「会場周辺の今を見る」から遷移。
- 共通イベントDBとの照合、期限切れイベント、座標不正、戻る導線を確認。

### L5 運用拡張

- 半径指定、現在地基準、地域別台帳拡大。
- 稼働確認、規約再確認、停止処理を管理画面へ追加。
- 利用状況を見て埋込対象を限定拡大。
