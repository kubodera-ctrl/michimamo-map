# 開発18 埼玉県AED原票の厳格照合

2026-09-16。開発17終了時の公開AED 46,945件から開始し、開発16の地域カタログ追跡対象に残っていた埼玉県21自治体を再回収した。

## 回収結果

- 現行扱いの公式原票: 12自治体
- 古い公式原票のため証跡のみ保存: 7自治体
- 取得・解析失敗: 2自治体（鶴ヶ島市、白岡市）
- 12自治体の現行原票はいずれも施設単位座標を持たず、住所のみだったため厳格住所照合へ切り替えた。

## 公開しなかった対象

- 久喜市126件: 原票に住所がなく、施設名と設置場所だけのため合格0件。
- 毛呂山町34件・寄居町40件: 厳格住所照合の全条件を満たさず合格0件。
- 熊谷市、草加市、戸田市、富士見市、嵐山町、鳩山町、松伏町: 原票更新日が2023年より前のため現況情報として公開せず保留。
- 鶴ヶ島市: 最新XLSのダウンロード先がHTMLを返すため取得保留。
- 白岡市: 公式CSVを表として解析できず保留。

## 次の対象

埼玉県の残り12自治体について自治体公式ページの現行情報を追跡する。現行原票を回収できない対象は保留を維持する。その後、開発17から残る柏市、八千代市、匝瑳市、大網白里市、大東市、玉野市を再確認する。代表点、外部利用不可、古い年度データは公開しない。
