## 自動承認審査で止まった既存座標の監査

Supabaseから取得した既存1,726施設の住所を外部の位置情報処理に使用する操作が、自動承認審査で拒否された。一般的なAED作業の承認だけでは、コネクター由来住所の外部利用は承認されていないとの判定。
**同じ送信を別経路・別スクリプトで再試行してはならない。明示承認、または外部送信しない実質的に安全な代替手段が必要。**

中断時点の手元結果910件を確認。382件は公開座標が町・市の代表点と厳密に一致したため、元レコードを残して `active=false`、ステージングをholdに変更。406件は位置レベル8・既存座標一致。122件は位置差異等の確認が必要。816件は未再照合。

- `confirmed_low_precision.json`: 公開停止の判定根拠となるキー・座標・精度。
- `quarantine_previous_state.json`: 変更前の公開状態・ステージング審査情報。復帰は正式な施設座標確認後に行う。
- `quarantine_low_precision.sql`: rollback検証とcommit済み。再実行不可。
- 入力住所・中断時の未加工結果はGitへ追加せず、当該作業環境 `/workspace/scratch/fbe257d3bcc9/aed-private-audit-checkpoint/` に分離。

この制約は既存監査の外部処理に関するもの。自治体が公開した原本からの新規処理・本番反映は別途実行済み。
