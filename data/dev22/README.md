# 開発22 公開基盤・広域クラスタ

## 対応
- クラスタを件数による緑/黄から施設種別の固定色へ変更。警察署・交番・駐在所は青、AEDは赤、将来の子供110番は緑。種別の短いラベルと正確な件数を表示。カテゴリ分離、表示フィルター、ズーム16で個別化を維持。
- 開発21の活動履歴・否認理由・再投稿導線は実装済み。作り直していない。
- AED投稿のINSERT権限を証拠入力列だけに限定。審査状態、審査者、メモ、日時、不正フラグはサーバー管理。本人の非公開領域に写真が存在することを必須化。
- 一般写真の匿名アップロードを廃止。ログイン・有効アカウント・本人フォルダーを必須化、10MB/JPEG・PNG・WebP制限。公開済みURLは維持。
- 一般投稿の写真もJPEG再生成でEXIF削除。個人情報が写らないことの確認欄を追加。実装されていないAI検閲・モザイク処理を実行中とする表示を訂正。自動顔/ナンバーマスキングは未実装と明記。
- 写真差替えの非同期競合、変換失敗時の古い写真の誤送信、閉じたフォームへの変換結果反映を防止。
- ログイン専用RPC8本とトリガー2本から不要な匿名実行権限を削除。公開地図・出典・ランキングのRPC3本は維持。
