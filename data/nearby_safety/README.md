# 近くの安全スポット（2026-09-16）

- 地図の「近くのAED」から現在地の近い順一覧。AED／交番・警察署・駐在所を切替。未承諾の子供110番データは含めない。
- 半径5km・最大20件、手動で10kmまで拡張。位置情報拒否・失敗では明示的に地図中心を選択できる。中心基準を「現在地」と偽らず表示。
- 直線距離、GPS取得時刻・精度、設置場所・利用時間（不明も明記）、出典・基準日、Googleマップへのナビ。開館中や経路最短を保証する表示はしない。
- viewportの1,500件上限から独立した検索。active・非重複・verified、公開施設情報のみ。位置履歴をDB/localStorageに保存しない（通常のインフラ通信ログとは別）。
- `20260916043232_nearby_safety_spots`適用済み。private SECURITY DEFINERによる公開項目の限定投影＋public INVOKERラッパー。anonも利用可能、元表は非公開のまま。
- 半径10km・20件上限、座標/種別の検証、既存type/lat/lngインデックスで候補を絞り、球面距離順にソートしてからLIMIT。地図のフィルター非表示状態にも依存しない。
- SQLテスト：台場のAED/警察、大阪のAED/警察、山梨のAED、札幌の警察の6条件で全表の独立した球面余弦距離計算と上位20件を比較。一致。匿名取得、NaN/過大半径/過大件数/未対応種別の拒否を確認。
- JS4テスト：GPSと地図中心の競合、カテゴリ応答の逆転、閉じた後の応答・位置拒否、HTMLエスケープと失敗時の旧結果消去。
- Security Advisorで新RPCに関する指摘なし。既存の公開読み取りRPCや内部テーブル等の指摘は残り、警告ゼロとは扱わない。
