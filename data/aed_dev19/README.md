## 全国ルート別の判定

1. BODIK AED API / 自治体標準オープンデータセット
   - 再利用条件をメタデータ単位で審査済み。
   - 全国再取得は28,534行で前回と同数。
   - 大規模配布元のAPI上限超過分は、過去作業で公式元CSVを取得して補完済み。
2. AEDオープンデータプラットフォーム
   - 公開ページはCC BY 3.0を表示。
   - `aed.azure-mobile.net` APIは提供終了で、都道府県一覧APIもタイムアウトしたため取得0件。
3. G空間情報センター
   - 旧AEDリソースID `bfc3b8da-073a-4e3b-98c7-ff2f40edb621` は匿名APIで閲覧不可。
   - 公開データとして再取得できないため投入0件。

   - 掲載件数は大きいが、第三者によるデータ一括再利用の許諾を確認できない。
